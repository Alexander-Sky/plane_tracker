# ✈️ Plane Tracker

Приложение для отслеживания самолётов в реальном времени в воздушном пространстве любой страны мира.
Программа использует открытые API для получения данных о местоположении, высоте и скорости полёта, 
сохраняет историю в JSON-файл и предоставляет удобный интерфейс для фильтрации и анализа.

##  Функциональность

-   ** Получение данных по стране:** Введите название, и программа найдёт все самолёты над указанной территорией.
-   ** Сохранение в JSON:** Все загруженные данные автоматически сохраняются в файл `data/planes.json`.
-   ** Топ по высоте:** Показывает `N` самолётов, летящих выше всех.
-   ** Фильтр по стране регистрации:** Оставляет только самолёты из заданных стран (например, `Germany, France`).
-   ** Фильтр по диапазону высот:** Позволяет отобрать самолёты, например, `от 5000 до 10000 метров`.
-   ** Просмотр сохранённых данных:** В любой момент можно посмотреть все ранее загруженные самолёты.
-   ** Удобный консольный интерфейс:** Интуитивно понятное меню с эмодзи. 🎨

##  Технологии

-   **Python 3.14** — язык программирования.
-   **Poetry** — управление зависимозтями.
-   **requests** — взаимодействие с внешними API.
-   **pytest, pytest-cov** — тестирование и проверка покрытия.
-   **black, isort, flake8, mypy** — поддержание чистоты и стиля кода.
-   **API:**
    -   `nominatim.openstreetmap.org` — для получения географических границ стран.
    -   `opensky-network.org` — для получения данных о самолётах.

##  Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/Alexander-Sky/plane_tracker.git
    cd plane_tracker
Установите зависимости с помощью Poetry:

bash

poetry install
Активируйте виртуальное окружение:

bash
poetry shell
Запустите программу:

bash
python main.py
